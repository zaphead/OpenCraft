# assets/pack attribution

Playable art + sounds for OpenCraft, loaded unmodified at runtime.
A `--pack` / `OPENCRAFT_PACK` path overrides this directory.

Sources (both user-provided, merged without edits except this file):

- Textures: "Default Texture Pack 26.2 Template.zip"
  (pack description points at Texture-Packs.com; see Texture-Packs.com.txt)
- Sounds: "Sound Pack.zip" (its own pack.mcmeta/pack.png omitted on merge
  to keep the texture pack's; every sound file kept as-shipped)

Provenance note: these files ship default-vanilla-looking content. They are
NOT committed to git until the owner confirms they are community-made and
clear to distribute — raw Mojang/Microsoft rips stay banned per AGENTS.md.
Local play needs no commit: the client reads this directory as-is.
